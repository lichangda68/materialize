# 教材示意图库

把《材料科学基础》教材里的关键示意图放到本目录，服务会自动按「高频概念」匹配到对应的输入句子：命中的句子用这里的**教材原图**，未命中的回退到 AI 自画的 SVG 示意图。

## 使用方法

1. 从教材 PDF 截图对应概念的示意图（PNG/JPG 均可）。
2. 文件**必须以概念关键词命名**（见下表），例如 `位错.png`、`铁碳相图.png`。
3. 放进来后**重启服务**（`npm start`）即生效。

> 支持格式：`.png` `.jpg` `.jpeg` `.webp` `.gif`

| 扩散.png | 扩散、渗碳、扩散系数、阿伦尼乌斯、反应扩散 |

| 再结晶.png | 再结晶、回复、晶粒长大、晶界 |
| 晶体结构.png | 晶体、晶格、晶胞、晶面/晶向、密排、空间点阵 |
